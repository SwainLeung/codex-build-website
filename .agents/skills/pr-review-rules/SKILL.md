---
name: pr-review-rules
description: 对 PR 或待合并 diff 做结构化审查，依据仓库规则和行为证据指出可复现的问题。
---

确定基线和候选提交，阅读变更文件、原调用方、适用 AGENTS.md、关联 Issue 和测试。重点检查旧输入、异常和重试、权限变化、生成物来源，以及断言是否被弱化。

每条意见给出严重程度、文件及位置、规则或验收编号、触发条件、用户影响、建议复测。把风格偏好留给现有格式化规则。缺少必要证据时说明待验证假设。

收尾写明阻塞项、已验证范围、待补范围。修复后用原反例核对新提交；如无发现，说明审查范围与剩余盲区。默认产出本地报告或 PR 草稿。
