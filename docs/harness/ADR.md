# 架构决策记录模板

决策影响多个模块、对外接口或日后迁移成本时，复制到 `docs/adr/<编号>-<主题>.md`，或使用团队已有记录。把链接写回相关规格或项目卡。

| 项目 | 填写内容 |
| --- | --- |
| 编号、状态、日期、决策人与参与模块 | 提议 / 采纳 / 被替代，注明关联 Issue |
| 问题和约束 | 当前用户、现有接口、必须满足的判据 |
| 可行选项 | 每项说明收益、代价与兼容影响 |
| 选定方案与理由 | 说明哪一条证据改变了选择 |
| 后果与恢复办法 | 已知限制、迁移步骤、可逆性与负责方 |
| 何时复查 | 可观察的触发条件、证据链接、替代记录 |

例：两个子项目共享验证入口时，可以保留各自原生命令，由根脚本统一调用。验收时让其中一个子项目故意失败，核对根脚本和 CI 均返回失败。
