# 阶段计划与续做记录

跨会话、跨模块或需要交接时，复制到 `docs/harness/phases/<issue>-<phase>.md`，也可把下表贴入现有 Issue。一个阶段以一项可独立验收的用户行为为单位。

| 目标行为、成功判据、范围外事项 | |
| 依赖与输入 / 上一阶段证据 | |
| 涉及模块、局部指令及可编辑路径 | |
| 最小步骤、验证命令、退出条件 | |

## 追加执行记录

| 时间 / 执行人 | 分支、基线 SHA、工作树差异 | 动作和结果 / 失败证据 | 状态 / 下一步 |
| --- | --- | --- | --- |
| | | | |

续做时比对当前分支、提交、未提交差异及上次失败的命令。若基线已变化，先重跑受影响的最小检查再继续。阶段结束时写下有效产物、仍未验证的路径，以及下阶段从哪里开始。

例：上次已验证解析器能拒绝空输入，CLI 的退出码还未核对。下次先复查解析器提交及工作树，再从 CLI 入口传入空文件并断言退出码和错误信息。
