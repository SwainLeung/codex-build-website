# AI LABS Website System — Visual Direction

## Intent

An editorial systems notebook: high craft, low decoration-for-decoration's-sake. The page should feel like a creative director and an engineering lead marked up the same working board.

## Visual tokens

- Ink: `#17221d` (forest green)
- Paper: `#eae8e1` (warm ivory)
- Field: `#d7dfd4` (sage)
- Signal: `#e84f32` (coral)
- Charge: `#d7ff8a` (acid lime)
- Type: DM Sans for UI, Instrument Serif for moments of judgment, DM Mono for metadata.

## Layout and motion

- Use asymmetric editorial layouts, fine rule lines, compact metadata, and one oversized typographic moment per section.
- Preserve generous whitespace and one dominant reading path.
- Motion must explain state or hierarchy. Respect `prefers-reduced-motion`; never require motion to access content.
- Avoid generic neon gradients, dashboard chrome, fake device mockups, stock photos, and decorative text inside images.

## Asset rules

- Put reusable, publishable raster assets in `public/assets/` with a clear filename and source record.
- Use only assets with a known creation path and publishing rights. Do not commit raw third-party transcripts, screenshots, or unlicensed references.
