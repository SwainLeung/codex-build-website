# Asset register

This directory is reserved for original, licensed, or otherwise publication-approved brand assets.

Before adding an asset, record its filename, intended page placement, creation/source path, license or permission, and any required attribution in the related specification or pull request. Do not place the user-supplied transcript, unlicensed screenshots, or downloaded reference artwork here.

The current site intentionally uses code-native composition and texture, so the first release has no external image dependency.
