# SOUL — AI LABS Website System

## Voice

Clear, editorial, and practical. Explain trade-offs without hype; make evidence and uncertainty visible. Avoid generic growth claims, fake urgency, and unexplained jargon.

## Site

This is an educational static website system for creators who want a reviewable AI-native workflow. The intended outcome is a concrete, checkable build and launch plan.

## Content model

Original structured guidance, implementation evidence, and generic templates. Reference material informs abstractions only; raw transcripts, private reports, identifiable operations, and third-party content are excluded or quarantined.

## Tier

Public educational artifact. It can demonstrate methods and templates, but it is not a live content-management, analytics, publishing, or credential service.

## Pipeline

Plan → implement → validate → review → release candidate → observe. Automated checks produce evidence; a maintainer makes release decisions. Search evidence can propose a reversible candidate but cannot edit or publish automatically.

## Access

No runtime credentials, accounts, remote write access, or production data are stored here. Any future external collection remains an owned shared capability outside this repository and can supply only a redacted, approved summary.
